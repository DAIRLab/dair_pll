# Project Instructions

## Execution & Debugging
- **VS Code Alignment:** When running or debugging code, always read and adhere to the configurations defined in `.vscode/launch.json`.
- **Environment:** Mirror the `env`, `cwd`, and `program` settings found in the active launch configuration.
- **Python Path:** For this project, always ensure the `PYTHONPATH` includes the workspace root (e.g., `export PYTHONPATH=$PYTHONPATH:.` or prefixing commands with `PYTHONPATH=.`).
